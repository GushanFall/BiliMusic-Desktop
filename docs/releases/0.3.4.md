# BiliMusic 0.3.4

- 统一在线歌单导入入口，自动识别网易云、QQ 音乐、酷狗、酷我和咪咕链接；支持保留进度、继续导入及重新匹配。
- 优化导入请求调度、结果缓存和限流等待，批量导入期间合并云同步，减少重复请求。
- 改善上次播放队列与进度的保存，返回 UP 主合集时保留浏览位置，统一播放列表和听歌统计中的分 P 标题。
- 预缓存下一首的起播数据，减少切歌时的重复加载。
- 桌面播放列表支持拖动调整宽度、点击空白收起，并新增可自定义的刷新与同步快捷键。
- 编辑歌曲信息时可重新读取 B 站信息，统一导入歌单、新建收藏夹等界面的样式。

- 新增大屏版，适用于 Android 车机与 TV，支持触控、遥控器、视频与弹幕，音乐库和听歌记录可与其他端同步。
- 修复桌面窗口与托盘交互，记忆桌面歌词位置，完善下载与封面显示。

本次沿用 V2 同步格式，建议各设备一并更新。
